## 4. 前端交互与轨迹渲染验证

Chrome CDP 临时自动化脚本验证了以下场景，全部通过：

- 成功发送、等待气泡、成功替换、自动滚动；
- 空输入拦截、输入法 Enter、Shift+Enter、Enter 发送；
- 业务失败、HTTP 400 恢复上一轮轨迹、409 忙碌、网络失败、请求失败恢复草稿；
- 处理中禁用输入/发送/清空，防止重复提交；
- 清空确认、取消清空、清空失败保留会话；
- 轨迹概览：问题、部分成功状态、3 次模型请求、3 次工具调用、2 个工具轮次、混合调用、起止时间、总耗时、Token、停止原因；
- 并行/单工具轮次、调用编号、执行方式、真实起止与耗时；
- 工具参数/结果 `<details>` 默认收起并可展开；
- 失败工具错误类型与消息；执行中调用显示“执行中”；
- 无工具状态；Token 缺失显示“未返回”；时间缺失显示“未记录”；
- 工具结果中嵌入的 HTML 仅作为文本展示，未生成元素或执行脚本。

> 上述 CDP 脚本为验收用临时脚本，未纳入仓库；可复现的核心逻辑已由 pytest 覆盖。
